# Bulk state changes on Daily Attendance

**Status:** done

**Date:** 2026-11-21

**Goal:** HR can select employee-days on Daily Attendance, review a shared state change, and apply it in one submission. The existing rules still calculate attendance and pay for each selected shift date.

Companion to [the current attendance plan](2026-11-13-follow-odoo-configurable.md) and [Set as off in Daily Attendance](2026-11-19-daily-set-as-off.md). The existing Edit day sheet sets or clears an absence for one person and date range. Bulk state editing works on the stored rows at `/attendance/days`. Rostered days off, shift changes, punch edits and payroll adjustments use their existing controls.

## 1. Approved behavior

- **BDS1 · Selection.** Add a checkbox per row and **Select this page** in the table header. Show the number selected and a **Change state** action. The unit of selection is one employee and one stored shift date, so HR can select several employees on one date or several dates for one employee. Select all acts on the current page of results. Changing any filter or page clears selection and dismisses a stale review. After a successful save, keep the current filters and let existing pagination handle a result set that shrinks.
- **BDS2 · Review and save.** In one dialog, choose Leave, Sick, Mission, No show, Other, or Clear state, and enter a reason. Review the selected employee-days with their shift dates, current and proposed states, and whether punch evidence exists. Show counts for rows that will change, already match, or are blocked. Clear state removes the absence and lets existing roster and punch rules recalculate the day. An existing personal absence can be replaced or cleared with confirmation. Pattern missions and other owner-managed absences are blocked with a row-level reason. An inactive or missing employee-day also blocks the save. Rows already in the chosen state, or already clear, are counted as unchanged. If any row is blocked, HR can remove it and confirm a fresh review. Save commits all reviewed changes together.
